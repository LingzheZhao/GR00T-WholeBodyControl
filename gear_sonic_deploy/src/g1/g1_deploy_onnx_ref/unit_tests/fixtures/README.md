# Independent FK golden

`fk_mujoco_golden.hpp` is generated by MuJoCo 3.11.0 from the canonical G1
MJCF and the Mode-5 contract. The generator addresses every hinge by its MJCF
joint name and uses MuJoCo's `mj_forward`; it does not import or reproduce the
deployment `RobotFK` implementation.

Regenerate to stdout in the pinned image, without network, GPU, devices, or a
writable checkout:

```sh
docker run --rm --interactive \
  --network none --read-only --tmpfs /tmp --cap-drop ALL \
  --security-opt no-new-privileges --env NVIDIA_VISIBLE_DEVICES=void \
  --volume "$PWD:/wbc:ro" --entrypoint python3 \
  sha256:ccbb35e993276b33d338dfd6e273a5b2f83bbba4a7e678f3bd1fb65c707325a7 \
  /wbc/gear_sonic_deploy/src/g1/g1_deploy_onnx_ref/unit_tests/fixtures/generate_fk_mujoco_golden.py \
  --wbc-root /wbc
```

Review the model and contract digests embedded in the output before replacing
the checked fixture. Velocity tests remain separate: they use analytically
known 50 Hz finite differences because `mj_forward` supplies poses, not the
deployment code's trajectory-differencing convention.
